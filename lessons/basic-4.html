TEXT LESSON

基本を理解する

基本のショートカットに慣れてきたら、次は「知っていると一気に差がつく」便利ワザを覚えましょう。特に画面の切り替えとスクリーンショットは、在宅ワークで毎日使う場面が出てきます。ここで紹介するものも、全部を一度に覚える必要はありません。「便利そう」と思ったものから1つずつ試してください。

この教材のゴールは次の4つです。

  • アプリやタブを、マウスなしでサッと切り替えられる
  • 画面の好きな部分をスクリーンショットで画像にできる
  • コピー履歴と画面2分割という「時短の飛び道具」を知る
  • ブラウザでの調べもの・タブ操作をもっと速くできる

ウィンドウ・アプリを素早く切り替える

調べものをしながら文章を書く、AIに聞きながら作業する——在宅ワークでは、複数のアプリを行ったり来たりする時間が意外と長いのです。この操作を知っているとマウスに手を伸ばす回数がぐっと減ります。

  • Alt + Tab：開いているアプリを切り替える。Altを押したままTabを何度か押すと、一覧から選べます（Macは ⌘ + Tab）
  • Ctrl + T：ブラウザで新しいタブを開く
  • Ctrl + W：今のタブ・ウィンドウを閉じる
  • Ctrl + Shift + T：間違えて閉じたタブを復活させる。「あっ、消しちゃった！」の救世主です

スクリーンショット（画面の写真）を撮る

画面の一部を画像として保存できる機能です。「エラーが出たので見てほしい」「デザインのこの部分を直したい」など、言葉で説明しにくいことを一発で伝えられるので、クライアントとのやり取りで大活躍します。Windowsでの手順はこうです。

  1. 「Windowsキー + Shift + S」を押す（画面が少し暗くなります）
  2. 撮りたい範囲を、マウスでドラッグして囲む
  3. 撮った画像はコピーされた状態になるので、チャットやメールの入力欄で Ctrl + V を押して貼り付ける
  4. 画像として保存したいときは、撮った直後に画面右下に出る通知をクリックし、保存ボタンを押す

Macの場合は「⌘ + Shift + 4」で範囲を選ぶと、デスクトップに画像ファイルとして自動保存されます。

コピーの履歴を呼び出す

Windowsでは、対応環境でWindowsキー＋Vからクリップボード履歴を利用できます。必要な場合だけ有効にし、パスワードや顧客情報が履歴へ残らないか注意してください。共有端末では特に、利用後の履歴や同期設定を確認します。

デスクトップをすぐ表示する

作業中に「デスクトップに置いたファイルをすぐ見たい」というときは、「Windowsキー + D」を押すと、開いているウィンドウがすべて一瞬隠れてデスクトップが表示されます。もう一度押せば、元の画面にすぐ戻れます。会議中に画面を共有していて、急に別の資料を映したくないときにも使える、覚えておくと安心なワザです。

画面を左右に2分割する

Windowsで「Windowsキー + ←」または「Windowsキー + →」を押すと、今のウィンドウが画面の半分にピタッと収まります。左に資料、右に書きかけの文書、と並べれば、切り替えすら不要になります。「見ながら書く」作業で一番効くワザです。もう片方の半分には、次に使いたいアプリの一覧が自動で表示されるので、そこから選べばもう半分もすぐ埋まります。Macの場合は、ウィンドウ左上の緑色の丸ボタンを長押しすると、同じように画面の半分に配置するメニューが出てきます。

ブラウザ（インターネットを見る画面）の便利ワザ

調べもの中心の作業では、ブラウザ内の操作も覚えておくと差が出ます。

  • Ctrl + タブをクリック：リンクを新しいタブで開く。今見ているページを閉じずに次を確認できます
  • Ctrl + タブキー：開いているタブを順番に切り替える
  • Ctrl + L：アドレスバー（URLを打つ場所）にカーソルを一発で移動
  • Ctrl + 数字（1〜9）：左からその番号のタブに一瞬でジャンプ

よくあるつまずきと対処法

  • Windowsキーってどれ？ → キーボード左下、Ctrlの近くにある「田」のような旗のマークのキーです
  • スクリーンショットがどこに保存されたか分からない → 保存先はSnipping Toolなどの設定によって変わります。撮影後の通知とアプリの保存設定を確認し、必要なら明示的に名前を付けて保存します
  • Alt + Tabで目が回る → Altを押したまま、ゆっくりTabを1回ずつ押せば、順番に選べます
  • 2分割にしたウィンドウを元に戻したい → ウィンドウ上部をつかんで画面の真ん中まで軽くドラッグすれば、元のサイズに戻ります
  • 「Win + V」を押しても何も出ない → 初回だけ「クリップボードの履歴を有効にする」というボタンを押す必要があります。表示された案内に従ってオンにしてください
やってみよう今この画面の一部をスクリーンショットで撮って、自分あてのメールやLINEのキープメモに貼り付けてみましょう。慣れてきたら「Windowsキー + ←」で画面を2分割し、片方にこの教材、片方にメモ帳を開いて実際に操作しながら読んでみてください。
POINTこれらは「便利だな」と思ったものから1つずつでOK。特にスクリーンショットは、この先のコースで質問をするときにも使うので、今日必ず一度試しておきましょう。
POINTショートカットは「知っている」と「使っている」の間に大きな差があります。今日紹介したものを、次に似た場面が来たときに一度でも使ってみることが、定着への一番の近道です。

画面を並べる目的を決める

教材を見ながらアプリを操作するなら、左に説明、右に作業画面を置きます。原稿の修正なら、元の文章と修正版を並べます。ウィンドウを増やしすぎると文字が小さくなるため、まず必要な2つだけに絞りましょう。小さい画面では、無理に分割せずアプリ切り替えでも十分です。

ブラウザのタブとアプリのウィンドウは別の単位です。タブを切り替える操作と、アプリを切り替える操作を混同すると迷いやすくなります。まずマウスで対象を確認し、その動きをキー操作へ置き換えると理解が進みます。

スクリーンショットは状況説明の資料

エラーの相談では、画面全体を1枚送るより、エラー文とその直前の操作が分かる範囲を示す方が役立ちます。ただし切り取りすぎると、どのアプリなのか分からなくなります。サービス名、エラー文、必要な操作部分が分かる範囲を選びましょう。

通知、別案件のタブ、メールアドレス、パスワード、認証コードが写り込まないか、保存した画像を開いて確認します。隠す必要がある箇所は、不透明な塗りつぶしなどで読めない状態にした画像を新しく書き出し、その完成ファイルを再確認します。

手を動かす：実践の手順

  1. 01
    教材と練習文書を開き、ウィンドウの配置機能で左右に並べる。読みにくければ片方ずつ表示する。
  2. 02
    教材を1段落読み、練習文書へ要点を1行書く。アプリ切り替えも使って違いを比べる。
  3. 03
    練習文書の一部分をスクリーンショットで保存する。撮影後は保存先を確認する。
  4. 04
    保存した画像を開き、余計な情報がないか、文字が読めるかを確認し、説明文を添える。
