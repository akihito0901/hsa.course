TEXT LESSON

基本を理解する

在宅ワークを始めるとき、まず必要になるのがパソコンです。「どんなパソコンを買えばいいの？」「届いたけど、何をすればいいのか分からない」——多くの人が、この最初の一歩でつまずきます。この教材では、難しい専門用語をできるだけ使わずに、パソコン選びから最初の設定、届いてから1か月以内にやっておきたい点検までを一緒に進めていきます。

この教材を読み終えると、次のことができるようになります。

  • 自分に合ったパソコンを、迷わず選べる
  • 買ってはいけないパソコンの特徴が分かる
  • 届いたその日に、最低限の設定を自分で済ませられる
  • 「動きが遅い」「音が出ない」などの初期トラブルを自分で解決できる

どんなパソコンを選べばいい？

結論から言うと、最初は「そこそこの性能のノートパソコン」で十分です。高価なものを買う必要はありませんし、中古でも問題ありません。このスクールで学ぶ内容（文章作成・Canvaでのデザイン・AI活用など）は、ほとんどがインターネット上で動くので、高い性能を必要としないからです。

お店やネットで選ぶときは、商品説明のなかから次の3つの数字だけ確認してください。

  • メモリ：8GB以上。メモリは「作業机の広さ」です。狭いと、アプリをいくつか開いただけで動きが遅くなります。予算に余裕があれば16GBを選ぶと、この先何年も余裕を持って使えます
  • ストレージ：SSDで256GB以上。ストレージは「保管庫」です。SSDという種類なら電源を入れて数十秒で使い始められます。「eMMC」という種類は動作が遅いことが多いので避けましょう
  • CPU（処理を行う部分）：シリーズ名だけでなく世代や型番で性能が異なります。使うアプリの動作要件と実際の操作を確認して選びます

WindowsとMacは、使うソフトと周囲のサポート環境で選びます。まず手元の機器で学習を試し、買い替える場合は動作要件、更新対応、保証、総費用を比較してください。販売価格は機種や時期で変わるため、購入時の表示で確認します。

新品・中古・どこで買う？

新品と中古のどちらでも、必要な作業ができることと、更新・保証の条件を確認します。中古はバッテリーや付属品の状態、OSの正式な対応、返品条件まで点検します。販売店というだけで品質が保証されるわけではないため、商品ごとの条件を見ましょう。

  • バッテリーの状態（「バッテリー最大容量◯％」の表示があるか）
  • 保証期間（最低でも1〜3か月の動作保証があるか）
  • OSが正式にサポートされ、今後も更新を受けられること。Windows 10の通常サポートは2025年10月14日に終了しています。拡張更新制度の対象や期限は公式案内で確認します

逆に、避けたいパソコン

安さにひかれて次のようなものを買ってしまうと、「動きが遅くてやる気がなくなる」原因になります。値段より先に、ここをチェックしましょう。

  • メモリが4GBのもの（今の時代では足りません）
  • ストレージが「HDD」のもの（起動やファイルを開くのに時間がかかります）
  • 発売から7〜8年以上たった古いもの（更新が受けられない場合があります）
  • 「Windows 11 に対応していない」と書かれているもの（今後、安全に使い続けられなくなります）
  • 極端に安いタブレット兼用パソコン（キーボードが小さすぎて長時間の作業に向きません）

届いたら最初にやる設定

パソコンが手元に来たら、次の順番で進めましょう。電源を入れると案内の画面が始まるので、基本は画面の指示に従っていけば大丈夫です。1つずつ、焦らず進めてください。

  1. 電源を入れて、最初の設定案内（言語や地域の選択）を進める
  2. インターネット（Wi-Fi）につなぐ。自宅のWi-Fiの名前とパスワードは、ルーター（ネットの機械）の側面や底面のシールに書いてあります
  3. Microsoftアカウント（またはApple ID）の作成・ログインを求められたら、これから使うメールアドレスで登録する。この後の章で作るGoogleアカウントとは別物なので、混同しないようにしましょう
  4. 端末のサインイン方法と画面ロックを設定し、復旧に必要な情報を安全に管理する。パスワードを通常の共有メモへ保存しない
  5. 設定が終わったら、画面の明るさと文字の大きさを見やすく調整する（Windowsなら「設定 → システム → ディスプレイ」の「拡大縮小」で文字を大きくできます）
  6. 「Windows Update（更新）」が始まったら、終わるまでゆっくり待つ。初回は時間がかかることがありますが、故障ではありません
  7. マウスを使いたい場合は、この段階で接続しておく（USB接続タイプなら挿すだけ、Bluetoothタイプは「設定 → Bluetoothとデバイス」から追加します）

セキュリティソフトはどうする？

WindowsにはMicrosoft Defenderなどのセキュリティ機能があります。保護と更新が有効かを確認し、仕事で指定されたソフトや管理ルールがある場合はそれに従います。追加ソフトだけで安全が保証されるわけではありません。次の点も守りましょう。

  • 身に覚えのないメールの添付ファイルやリンクは開かない
  • 「無料」をうたう出所不明のソフトを、安易にインストールしない

最初の1か月でチェックしておきたいこと

買った直後は快調でも、後から後悔しないために次の点を早めに確認しておきましょう。

  • 不要な体験版ソフト（お試し版のウイルス対策ソフトなど）がプリインストールされていないか確認し、不要ならアンインストールする
  • 返品・交換の期限がある場合は、期限内に一度しっかり使って動作を確認する
  • 「Windows Update」を1度手動でチェックし、最新の状態にしておく（「設定 → Windows Update → 更新プログラムのチェック」）

よくあるつまずきと対処法

  • Wi-Fiのパスワードが分からない → ルーター本体のシールにある「暗号化キー」「KEY」「PASS」などの表記がそれです
  • 更新が何十分も終わらない → 電源を切らずにそのまま待てばOK。その間はスマホでこの教材の続きを読みましょう
  • 知らない言葉が出てきた → 後の章で学ぶAIに「〇〇ってどういう意味？」と聞けば、やさしく教えてくれます。今は全部理解しなくて大丈夫です
  • 動きがなんとなく遅い気がする → 最初の数回は、裏側で更新作業が進んでいることが多いです。1日ほど使い続けても改善しない場合だけ、購入店に相談しましょう
  • 音が出ない → 画面右下のスピーカーのマークがミュート（斜線）になっていないか確認しましょう
  • キーボードで記号がうまく打てない → 「設定 → 時刻と言語 → 言語と地域」で、キーボードが「日本語」に設定されているか確認してください
やってみようすでにパソコンがある人は、「設定」から文字の大きさを自分が読みやすいサイズに変えてみましょう。これから買う人は、通販サイトで「ノートパソコン メモリ8GB SSD」と検索して、予算内の候補を3つ探し、それぞれのメモリ・ストレージ・画面サイズをメモしてみてください。
POINTパソコン選びで迷ったら、家電量販店の店員さんに「在宅ワークで文章やデザインをしたい、予算は〇円」と伝えれば選んでくれます。完璧を求めず、まず1台用意することが第一歩です。
POINT迷ったときほど「一番高いもの」か「一番安いもの」を選びたくなりますが、どちらも失敗のもと。この章で挙げた条件を満たす「真ん中くらい」の1台を選べば、用途や動作条件と照合して判断しましょう。

性能の数字を、実際の仕事に置き換える

文章を書く仕事なら、ブラウザで教材と文書を同時に開き、文字を入力して保存できることが出発点です。画像制作なら、写真を何枚か配置したデザインを編集して書き出すところまで試します。動画編集は素材の解像度や長さで負荷が変わるため、文章作成と同じ条件で機器を選ばないようにしましょう。

メモリは同時に広げられる作業の量、ストレージは保存できる量です。ただし、その数字だけで快適さは決まりません。CPUの世代、空き容量、ネット接続、アプリ側の条件も関係します。買い替え候補は、使うサービスの動作要件と、返品・保証条件を確認して比較します。

初日に終わらせる動作確認

更新中に電源を切らなくて済むよう、充電器をつないで時間を確保します。仕事用に使う機器では、画面ロック・更新・復旧手段を先に整えると、教材を進める途中で困りにくくなります。暗証番号や回復キーそのものを、この教材の学習メモに記入しないでください。

音が出ない場合は、音量だけでなく出力先も見ます。Bluetoothイヤホンにつながったままのことがあります。映像が止まる場合は別のページも開いて、端末全体が遅いのか、通信や特定サービスの問題なのかを分けて考えましょう。

手を動かす：実践の手順

  1. 01
    OSの名称・バージョン、メモリ、空き容量を設定画面で確認し、機器の管理表に記録する。
  2. 02
    ブラウザで文書を作り、練習フォルダに保存する。閉じてから開き直し、内容が残っていることを確かめる。
  3. 03
    カメラとマイクのテストを行う。家の背景や通知に、他人に見せたくない情報が映らないかも確認する。
  4. 04
    画面をロックして解除できること、更新状況を確認できること、困ったときの問い合わせ先が分かることを点検する。
