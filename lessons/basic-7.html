TEXT LESSON

基本を理解する

ファイルの保存先は、パソコン本体だけでなく「Googleドライブ」を使うのがおすすめです。インターネット上（クラウド）に保存できるので、パソコンが壊れてもデータが消えず、他の人ともかんたんに共有できます。在宅ワークでは「納品物をクラウドで渡す」のが当たり前になっているので、ここでしっかり慣れておきましょう。

この教材のゴールは次の3つです。

  • Googleドライブにフォルダを作り、ファイルを保存できる
  • 共有リンクを作って、人にファイルを渡せる
  • 「閲覧のみ」と「編集可」を使い分けられる

Googleドライブとは

Googleドライブはインターネット上にファイルを保存するサービスです。容量の上限や残量はアカウントの管理画面で確認します。保存容量はメールや写真などと共用する場合があり、画像や動画の大きさによって使用量も変わります。まず現在の保存先と残量を把握しましょう。

クラウドに置くメリット

  • パソコンが壊れても、データはネット上に無事残っている
  • スマホからも同じファイルを見られる・編集できる
  • リンクを送るだけで、どんなに大きいファイルでも相手に渡せる（メール添付の容量制限に悩まされません）

基本の使い方

操作はとてもシンプルです。まずはフォルダを作って、ファイルを1つ入れるところまでやってみましょう。

  1. ブラウザで drive.google.com を開く（Googleアカウントでログインした状態で）
  2. 左上の「＋ 新規」ボタンを押し、「新しいフォルダ」を選んで名前を付ける
  3. フォルダを開き、パソコンのファイルを画面にドラッグ（つまんで運ぶ）すると、アップロードされる

フォルダの分け方は、基礎2で作った「仕事 → 案件ごと」のルールをそのまま持ち込めばOKです。パソコンの中とドライブの中で同じ構成にしておくと、迷子になりません。

共有リンクの作り方と注意点

ファイルやフォルダを他の人に渡すときは、リンクを作って送ります。

  1. 渡したいファイル（またはフォルダ）を右クリックし、「共有」を選ぶ
  2. 「共有」から必要な相手のアドレスを指定する。全体公開が必要な資料だけ、用途と機密性を確認して公開範囲を変更する
  3. 右側で「閲覧者（見るだけ）」か「編集者（書き換えOK）」を選ぶ
  4. 「リンクをコピー」を押して、チャットやメールに貼り付けて送る

使い分けの基本は、「納品物や見せるだけのものは閲覧者、一緒に作業するものだけ編集者」です。案件ごとにフォルダを分けておけば、フォルダのリンク1本で全納品物を渡せてスマートです。

容量が足りなくなったら

容量不足の際は、管理画面で使用量を確認し、不要な大きいファイルや重複を整理します。共有中の資料は相手への影響も確認し、必要なコピーを残してから削除します。追加容量が必要なら、現在の公式プランと費用を確認して検討しましょう。

「ごみ箱」と復元の仕組み

ドライブ上でファイルを削除しても、すぐには完全に消えません。パソコンと同じように「ごみ箱」に移動するだけなので、間違えて消してしまっても、左側メニューの「ごみ箱」を開いて該当ファイルを右クリックし、「復元」を選べば元に戻せます。ただし、ごみ箱の中のファイルは自動的に30日で完全に削除される仕組みになっているので、長期間戻らない可能性があるファイルは、ごみ箱に入れる前によく確認しましょう。

よくあるつまずきと対処法

  • 相手から「開けない」と言われた → 共有先のアドレスと相手のログインアカウント、付与した権限を確認します。開けないからと安易に全体公開へ変更しないでください
  • アップロードが終わらない → 大きいファイルは時間がかかります。画面を閉じずに待ちましょう
  • どこに保存したか分からなくなった → 画面上部の検索窓にファイル名の一部を入れれば、すぐ見つかります
  • 相手が間違えてファイルを消してしまった → 共有した本人（オーナー）であれば、ごみ箱から復元できます。編集者権限を渡すときは、このリスクも頭に入れておきましょう
  • スマホでファイルが開けない → ファイルの種類によっては専用アプリ（Googleドキュメントなど）が必要です。案内が出たら、そのままインストールすれば開けます
やってみようドライブに「仕事」フォルダを作り、何かファイルを1つアップロードして、その共有リンク（閲覧のみ）を作ってみましょう。作ったリンクを自分のスマホに送って開ければ、共有の流れは完璧です。余裕があれば、そのファイルを一度削除して、ごみ箱から復元する練習もしてみてください。
POINTGoogleドライブのアプリをスマホにも入れておきましょう。次の章で学ぶ「スマホ連動」の準備になります。
POINT「大事なファイルはパソコンだけでなくドライブにも」という習慣が、パソコンの故障や紛失からあなたのデータを守ってくれます。仕事の資料はできる限りドライブ経由で保存する意識を持ちましょう。

保存・同期・共有を分けて考える

保存はファイルを置くこと、同期は複数の場所の変更を合わせること、共有は他の人が使えるようにすることです。ドライブへアップロードしただけでは、相手に利用権限を渡したとは限りません。また、リンクをコピーしただけでも共有設定は変わらない場合があります。

仕事では、必要な相手を指定して共有する方法を基本にします。「リンクを知っている全員」は、リンクが転送された先でもアクセスできる可能性があります。公開資料と、顧客や受講生の情報が入った資料を同じ感覚で扱わないようにしましょう。

相手の役割に合わせて権限を選ぶ

完成物を見てもらうだけなら閲覧、修正の意見をもらうならコメント、共同で内容を変えるなら編集というように、必要な操作から考えます。便利だからと全員へ編集権限を付けると、誤変更や削除につながることがあります。フォルダの権限も一緒に確認してください。

容量はメールや写真など他サービスと共用する場合があります。空き容量の表示を確認してから、不要ファイルの整理を検討します。共有資料の削除やごみ箱の完全削除は、自分だけの判断で行わず、復元の必要がないか確認しましょう。

手を動かす：実践の手順

  1. 01
    個人情報を含まない練習文書をドライブへ置き、保存が完了していることを確認する。
  2. 02
    共有画面を開き、誰にどの権限を付けるかを決める。練習は自分で管理する別アカウントでもよい。
  3. 03
    共有リンクをコピーし、許可した相手側のアカウントで開けるかを確認する。自分の画面だけで判断しない。
  4. 04
    練習が終わったら不要な共有を解除し、再びアクセスできない状態になったかを点検する。
